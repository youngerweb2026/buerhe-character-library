# 不二何角色库

资源库作者：不二何。

可在本地直接打开的角色资产库，包含 218 组角色、436 张完整双视角角色卡和 218 份中文完整提示词，支持搜索、标签筛选及 Image 2.5 / Seedream 5.0 Pro 双模型对照。

## 下载完整角色库

请进入本仓库右侧的 **Releases**，下载 **Buerhe_Character_Library_v1.0.zip**。完整素材存放在 Release 附件中。

下载后完整解压，用 **Google Chrome** 打开文件夹内的 **打开角色库.html**。无需服务器、Python 或 Node.js。

请保留完整文件夹结构。个人选用记录与手动标签保存在各自的浏览器中。
